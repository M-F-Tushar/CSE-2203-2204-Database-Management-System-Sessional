# Part 3: Schema Design & Normalization

This Part focuses on validating and refining a relational schema using functional dependencies and normal forms — one of the highest-weight topics in the board exam.

## Why This Part Matters

Almost every board exam includes a dedicated normalization question (finding candidate keys, determining normal form, justifying BCNF vs. 3NF). Be comfortable computing attribute closures and applying Armstrong's Axioms by hand.
