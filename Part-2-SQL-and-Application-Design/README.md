# Part 2: SQL & Application Design

This Part covers the practical core of the course: writing SQL from basic queries to advanced procedural constructs, plus modern extensions into semi-structured data and NoSQL. This Part is the direct backbone of the **CSE 2204 Sessional (Lab)**.

## Chapters in This Part

| Chapter | Title | Focus |
|---------|-------|-------|
| [Chapter 3](Chapter-03-Introduction-to-SQL/README.md) | Introduction to SQL | DDL, basic queries, set operations, aggregates, subqueries, DML |
| [Chapter 4](Chapter-04-Intermediate-SQL/README.md) | Intermediate SQL | Joins, views, integrity constraints, authorization |
| [Chapter 5](Chapter-05-Advanced-SQL/README.md) | Advanced SQL | API access, stored procedures, triggers |
| [Chapter 8](Chapter-08-Complex-Data-Types/README.md) | Complex Data Types | Semi-structured data: JSON, XML, XPath, XQuery |
| [Chapter 10](Chapter-10-Big-Data-NoSQL/README.md) | Big Data (NoSQL) | NoSQL data models: document databases, key-value stores |

## Why This Part Matters

Nearly every Sessional/Lab test question and several theory questions (Q2, Q3, Q5, Q8) come directly from this Part. Practice writing and running actual SQL — joins, nested subqueries, triggers, and views — rather than only reading definitions.
