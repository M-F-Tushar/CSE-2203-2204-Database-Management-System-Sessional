# Part 1: Database System Foundations & Conceptual Design

This Part builds the conceptual foundation of database systems: what a DBMS is, how the relational model represents data, and how to design a database conceptually using the Entity-Relationship (E-R) Model before any SQL is written.

## Chapters in This Part

| Chapter | Title | Focus |
|---------|-------|-------|
| [Chapter 1](Chapter-01-Introduction/README.md) | Introduction | DBMS vs. file systems, data abstraction, database architecture |
| [Chapter 2](Chapter-02-Introduction-to-the-Relational-Model/README.md) | Introduction to the Relational Model | Relations, keys, relational algebra |
| [Chapter 6](Chapter-06-Database-Design-Using-the-ER-Model/README.md) | Database Design Using the E-R Model | Entity sets, relationships, cardinalities, ER-to-relational mapping |

## Why This Part Matters

Final exams consistently open with conceptual questions (Q1, Q2, Q3) drawn from these three chapters — differentiating DBMS from file systems, identifying keys, and drawing E-R diagrams for real-world systems (Library, Hospital, University). Master this Part first since later Parts (SQL, Normalization) build directly on these concepts.
