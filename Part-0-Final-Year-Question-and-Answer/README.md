# Part 0: Final Year Question and Answer

This Part is different from Parts 1–7. Instead of teaching topics chapter by chapter, it collects **real final examination question papers** (Theory: CSE 2203, Lab: CSE 2204) and gives **fully solved, easy-to-understand answers** for each question — written in the simplest possible language so even a complete beginner can follow along.

## How This Part Is Organized

```
📁 Part 0
├── 📁 Theory   (CSE 2203 — written/theory exam papers & answers)
│   ├── 📁 1st-Batch
│   └── 📁 2nd-Batch
└── 📁 Lab      (CSE 2204 — sessional/lab exam papers & answers)
    ├── 📁 1st-Batch
    └── 📁 2nd-Batch
```

- Click **[Theory](Theory/README.md)** for written exam question papers and answers.
- Click **[Lab](Lab/README.md)** for sessional/lab question papers and answers.
- Inside each, click a **batch folder** (1st Batch / 2nd Batch) to open its `README.md`, which contains the exact question paper followed immediately by the solved answer for each part.

## How to Use This Part

1. Read the question exactly as it appears in the paper (marks are shown in `[ ]`).
2. Read the **Answer** right below it — written in plain, simple words, with small examples so the idea sticks.
3. Cross-check with the main chapters in Part 1–7 if you want the fuller, more detailed explanation of the same topic.
